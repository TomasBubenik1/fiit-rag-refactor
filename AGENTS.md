# Repository guidance

For planning, running, comparing, documenting, or citing research experiments,
use [.agents/skills/experiment-records/SKILL.md](.agents/skills/experiment-records/SKILL.md).
Start historical lookup at [experiments/README.md](experiments/README.md), then
open only the relevant experiment and evidence. Ordinary code changes do not
require reading the experiment archive.

The formal assignment is in [docs/project_scope.md](docs/project_scope.md).
FIIT is the first case study for conversational RAG in bureaucratic institutions.
Distinguish planned work, measured observations, and supported conclusions.
